# Yungle
Yungle is an outer space simulator two player game designed as an upgrade to Space Dodge. Making it more fun, engaging and visually appealing.

## Installation
Use the package manager [pip](https://pip.pypa.io/en/stable/) to install pygame.
```bash
pip install pygame
```

## Usage
To play: Clone this Repo and run the main.py in terminal
``` bash
python3 main.py
```
